### 0.2.0

- **自动更新上线**：Daycatch 每 24 小时检查一次 GitHub Release，发现新版本时在右下角弹一张卡片，点「更新」即下载、校验 EdDSA 签名、替换 `/Applications` 里的 app 并自动重启。
- **后台不再抢焦点**：后台检查走「温和提醒」，不再突然弹出更新窗口；点卡片才进入 Sparkle 的安装流程。
- **设置页新增「关于」**：显示当前版本，可手动「检查更新」，也可关闭自动检查。
- **菜单栏右键菜单新增「检查更新…」**。
- **安装方式改为 Homebrew**：`brew install --cask luckyabner/daycatch/daycatch`。

> 说明：0.1.0 的安装包已经包含上述代码，这一版主要用于把「0.1.0 → 0.2.0」的自动更新链路完整跑通。

# Daycatch · macOS AI 日程助手 — 设计交付说明

> 配套文件：`design/` 目录下 4 个 `.dc.html` 设计稿源码（内联样式，可直接读取尺寸 / 颜色 / 字号）。
> 设计稿是在线画布的源码，依赖画布运行时 `support.js`，本地直接打开不一定能完整渲染；开发时把它当作"精确的样式参考"即可，以本文档为准。

## 1. 产品范围

菜单栏常驻应用（无 Dock 图标），三种识别入口 + 设置：

| 画板 | 文件 | 入口 | 说明 |
|---|---|---|---|
| ① 选中消息识别 | `Main.dc.html` | 全局快捷键 ⌥Space | 读取当前选中文字 → AI 提取 → 浮动结果面板 |
| ② 截图识别 | `Screenshot.dc.html` | 全局快捷键 ⌥⇧S | 框选区域 → 本机 OCR → AI 提取 → 结果面板 |
| ③ 手动输入 | `Manual.dc.html` | 菜单栏图标 / ⌥⇧Space | 弹窗内粘贴或输入文字 → 识别 → 添加；添加后右下角通知可撤销 |
| ④ 设置 | `Settings.dc.html` | 弹窗右上角设置按钮 | 快捷键 / AI 服务 / 默认写入 / 隐私 |

## 2. 建议技术栈

- SwiftUI + AppKit（`NSStatusItem` 菜单栏、`NSPanel` 非激活浮窗，避免抢走聊天软件焦点）
- 全局快捷键：`KeyboardShortcuts`（sindresorhus）
- 读取选中文字：Accessibility API（`AXUIElement` 的 `kAXSelectedTextAttribute`）；读不到时回退为模拟 ⌘C 读剪贴板，再恢复原剪贴板内容
- 截图：`ScreenCaptureKit` 或 `screencapture -i` 交互截图；OCR 用 Vision `VNRecognizeTextRequest`（`zh-Hans`, `en-US`），图片不上传
- 写入：EventKit（`EKEvent` 写日历、`EKReminder` 写提醒事项），需申请完整访问权限
- AI：按设置调用对应服务商，要求返回结构化 JSON（见 §6）
- API Key 存钥匙串（Keychain）

## 4. 组件

**结果面板（① ②）**：宽 480 / 520。从上到下依次为：来源标签（"来自选中文字" / "来自截图"）→ 标题 → AI 摘要（只有 ①）→ 事项列表 → 主按钮 → 底部一行（左："查看原文"链接；右：快捷键提示）。

**事项行**：
- 左侧日期列（宽 52）：上为月份，中为大号日期数字，下为星期
- 中间：类型行（实心 accent 圆点 = 日程，空心灰圈 = 待办）+ "日程 · 工作" / "待办 · 提醒事项"；标题；详情（时间 · 地点，以及线上会议号、提醒等）；必要时加一行 warning 提示
- 右侧：圆形勾选按钮，22×22，accent 填充 + 白色对勾 + 柔和阴影；未勾选状态为 1.5px `#CFCFCC` 细圈、无填充

**主按钮**：高 46，`fill.primaryButton` 底色，深色文字 15/600，右侧附灰色 ↩。文案随勾选数量变化，为"添加 N 项"。

**选中触发提示（①）**：选中文字下方显示白色胶囊，带阴影，内容为"添加到日历"和"⌥ Space"。

**截图（②）**：遮罩 `rgba(0,0,0,.38)`；选区 1px 白边，上方显示尺寸；选区下方白色胶囊显示状态（"文字识别完成（本机）· 已提取 3 项"），带"重新框选"按钮。

**菜单栏弹窗（③）**：宽 420。顶部是文字标签"识别 / 最近添加"，当前项下方 1.5px 下划线。输入框无边框、17px 字号；下方左侧为"粘贴""截图"文字按钮，右侧为"⌘↩ 识别"。添加后右下角出现白色通知卡片，带"撤销"。

**设置（④）**：左侧导航 200 宽，当前项用 `#F3F3F2` 底色。每一行左边是标签、右边是控件，行与行之间用 1px 细线分隔；控件统一 `#F3F3F2` 无边框。下拉框隐藏系统箭头，在右侧 12px 处放自定义下拉箭头。

## 5. 交互规则

1. 所有识别结果**先确认后写入**，绝不静默写入。
2. 快捷键：↩ 添加已勾选项；⌘E 编辑；esc 关闭；③ 中 ⌘↩ 识别。
3. 日程 → 日历（默认"工作"）；待办 → 提醒事项（默认"工作"列表）。
4. 相对时间（"明天""下周一""周四下午 3 点"）以当前日期解析；"1 个半小时"之类的时长换算为结束时间。
5. 原文缺失信息时按默认值处理（时长默认 1 小时），并在该事项上用 warning 提示标出。
6. 添加成功后显示通知，提供"撤销"（删除刚写入的 EKEvent / EKReminder）。
7. 隐私：截图只在本机 OCR，只把文字发给 AI；可选"添加后不保留原文"。

## 6. AI 返回结构（建议）

```json
{
  "summary": "周四下午 3 楼开 Q4 复盘会，会前需准备数据。",
  "items": [
    {
      "kind": "event",
      "title": "Q4 复盘会",
      "start": "2026-11-19T15:00:00+08:00",
      "end": "2026-11-19T16:30:00+08:00",
      "location": "3 楼大会议室",
      "notes": "线上会议号 728 391 045",
      "alarmMinutesBefore": 15,
      "inferred": []
    },
    {
      "kind": "todo",
      "title": "准备各自模块的 Q4 数据",
      "due": "2026-11-19T15:00:00+08:00",
      "inferred": []
    }
  ]
}
```

`inferred` 列出由 AI 推断、不是原文明确给出的字段（如 `["end"]`），界面据此显示 warning 提示。请求时传入当前日期时间和时区。
